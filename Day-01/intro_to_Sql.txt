Data:Data is a collection of raw facts and figures that can be processed to obtain meaningful information.Types of Data:Data can be classified into three types:Structured DataData that is organized in a fixed format, usually rows and columns.Example: Excel sheets, SQL databases, student records.Semi-Structured DataData that does not follow a strict table format but has some structure using tags, keys, or metadata.Example: JSON, XML, emails.Unstructured DataData that has no predefined structure or fixed format.Example: Images, videos, audio, social media posts, PDFs.file Management features:1)file can be created or deleted2)u can access it u can retrive it3)file organization4)file manipulation5)file sharing and file protection6)recovery backup files is Database:A database is an organized collection of data that is stored and managed so that it can be easily accessed, retrieved, updated, and deleted.What is DBMS?DBMS (Database Management System) is software used to create, store, organize, manage, retrieve, and update data in a database.\main building blocks of a database are:Table – Stores data in rows and columns.Example: Student tableField / Column – Represents one type of information.Example: Name, Age, MarksRecord / Row – Represents one complete entry.Example: 101, Reena, 21, 85Primary Key – Uniquely identifies each record.Example: Student_IDRelationship – Connects data between different tables.Example: Student ↔ CourseFeatures of DBMSData Storage – Stores large amounts of data in an organized way.Data Retrieval – Allows users to quickly search and retrieve required data.Data Security – Protects data from unauthorized access.Data Integrity – Ensures data remains accurate and consistent.Data Sharing – Allows multiple users to access and share data.Data Redundancy Control – Reduces unnecessary duplication of data.Backup and Recovery – Helps recover data after system failure.Concurrency Control – Allows multiple users to work with the database at the same time safely.Data Independence – Changes in data storage do not necessarily require changes to applications.Transaction Management – Ensures database operations are completed correctly.types of dbms:1)RDBMS2)NOSQL3)HIERARICHAL OR NETWORKDATA
